İstekler nasıl çevriliyor?
Claude Code · POST /v1/messages
model → satırdaki Command Code modeli; output_config.effort → effort tablosu; messages/tools → native mesajlar ve araçlar.
Codex · POST /v1/responses
model → aynı yönlendirme tablosu; reasoning.effort → effort tablosu; input/instructions/tools → native karşılıkları.
Yanıt akışı
Native NDJSON → Anthropic veya Responses SSE. Metin geldiği anda aktarılır. Tool argümanları doğrulanmış çağrı tamamlanınca gönderilir.
ChatGPT web ve Chat Completions
ChatGPT web bu yerel provider ayarını kullanmaz. /v1/chat/completions desteklenmez; OpenAI uyumlu istemci Responses göndermelidir.
